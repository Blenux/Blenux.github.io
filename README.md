Adding a blog post (automatic on GitHub):

1. Create a new HTML file in blog-posts/
   - Copy blog-posts/test.html as a template
   - Update title, date, tags, excerpt meta tags, and body content
2. git add / commit / push the new file
3. GitHub Actions will scan blog-posts/, rebuild js/blog-data.js, and commit it back
4. The post appears automatically on index.html (Recent Posts) and blogs.html
